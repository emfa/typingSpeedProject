# Button

Quiet is the default; the brass primary appears once per screen, on the action the screen is for.

`.q-btn`, plus `.q-btn-primary` or `.q-btn-small`.

- **You provide** a label that starts with a verb, sentence case: "Send RSVP", "Add to calendar", "Open in Maps", "Copy link".
- **Do** use the primary for "Send RSVP" on the guest's page and nowhere else on it. (While the guest confirms a form reply, "Yes, it was recorded" takes its place.)
- **On the host's page** the primary is "Add guest". Copying, exporting and removing are quiet.
- 44px tall so it is easy to hit on a phone; the small size (32px) is for table rows and link rows only.
