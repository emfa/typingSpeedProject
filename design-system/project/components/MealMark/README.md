# MealMark

The vegetarian and non-vegetarian marks: a dot in a square and a triangle in a square, each with its word or a count.

`<span class="q-meal q-meal-veg">` + `Qubool.mealMark('veg')` + the word; `q-meal-nonveg` and `'nonveg'` for the other.

- **You provide** the kind and the text beside it ("Veg", "Non-veg", or a count of plates).
- **Do** always pair the mark with text. The shapes differ so the two never rely on green against brown.
- **Don't** use `veg` or `nonveg` for anything but these marks; they are not success and error colours.
